# Aide-mémoire du vendeur

| Je veux…              | Je fais…                                                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Commencer la journée  | **Caisse** → fond de caisse → **Ouvrir la caisse**                                                                                    |
| Vendre                | **Nouvelle vente** → chercher (nom, code, IMEI) ou pastilles marque / modèle → IMEI du téléphone → paiement → **Encaisser**           |
| Prix de gros          | Choisir le **client grossiste**, ou atteindre la quantité de gros                                                                     |
| Remise trop forte     | Le **gérant** valide avec son identifiant et son code PIN                                                                             |
| Faire un troc         | Choisir le **client** (pièce d'identité) → **Troc** → modèle, IMEI, état → valeur → à revendre ou à réparer → encaisser la différence |
| Vendre à crédit       | Client (fiche complète, plafond) → **Vendre à crédit** → apport, tranches → **Encaisser** l'apport → imprimer le **contrat**          |
| Encaisser une tranche | **Crédits** → client → montant → moyen → **Encaisser** → reçu                                                                         |
| Envoyer la facture    | Client choisi → **Par SMS** ou **Par WhatsApp** (part même plus tard)                                                                 |
| Réimprimer un reçu    | **Ventes** → la vente → **Reçu, facture, WhatsApp…**                                                                                  |
| Retour d'un client    | Appeler le **gérant** (**Retours et échanges**)                                                                                       |
| Noter une dépense     | **Dépenses** → catégorie, montant, photo du reçu                                                                                      |
| Finir la journée      | **Caisse** → **Clôture** → compter chaque moyen → commentaire si écart                                                                |
| Plus d'Internet       | **Continuer** : tout part au retour du réseau                                                                                         |
| Opération en rouge    | Prévenir le **gérant** (Synchronisation → raison du refus)                                                                            |

**Codes utiles :** IMEI d'un téléphone : **\*#06#**. Références obligatoires pour Orange
Money, MTN MoMo et virement.

**Jamais :** partager son mot de passe ou son code PIN ; vendre un téléphone dont l'IMEI
est signalé ; se déconnecter avec des opérations en attente.
